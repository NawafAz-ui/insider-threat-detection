4. Decisions to check

  • Section 14 brings back a Capstone B section, which was removed on 6 November. The new research task asks for it.
  • The plan has no dates or owners, on purpose.
  • Nawaf's estimate of about 2.25 million sessions and 20 GB for the full CERT r4.2 is left out. The real release gave 470,591 sessions when it was prepared on 15 November, so that estimate is too high.
  • Package B1 now names only a CERT r4.2 sample, because SPEDIA already runs.
  • The results on generated data are higher than before (F1 0.99 instead of 0.95). The models now learn from 80% of the sessions, are tuned on all of them by cross-validation, and are tested on a different window, so the old and new values are not directly comparable. Generated data is easy, so neither says much about real logs.

5. Code changes behind the report

backend/tests/test_pipeline.py: the session test now checks that a session without a logoff ends at 21:00, twelve hours after its 09:00 logon. It failed when the cap was lifted, so it really checks the cap. The engine now splits the data into training and test only and tunes on out-of-fold scores of the training part (itd/models.py, engine.py, rules.py, cross_eval.py and scripts/run_experiments.py), with a new test. The main database was backed up to backend/backups/2026-11-16_1647 and rebuilt on SPEDIA. All 87 tests pass and 1 is skipped, and the dashboard builds.
